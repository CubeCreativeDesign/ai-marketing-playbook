# prompts/

Ready-to-use prompts for building the persona files your pipeline needs before it can produce good content.

| Prompt | What It Builds | Output File |
|--------|---------------|-------------|
| `build-writer-personas.md` | Voice profiles for the people writing your content | `personas/writer-profiles.md` |
| `build-reader-personas.md` | Buyer archetypes for the business owners you're targeting | `reference/reader-personas.md` |

## How to use these

1. Open a new Claude conversation (claude.ai or Claude Code)
2. Paste the contents of the prompt file
3. Follow the instructions — Claude will ask you questions or tell you what to paste in
4. Copy the output into the relevant file in this project

You don't need to be technical. If you have emails, proposals, or client notes sitting in your inbox, that's all the raw material you need.
