# Style Anchors (Photographic Prompts Only)

Photorealism is non-negotiable for photographic prompts. The medium is always photography —
no cartoon, no illustration, no anime, no stylized graphic art, no "digital illustration,"
no "3D render" as a stylistic look.

Style anchors come from **photography and editorial traditions only** — never illustrators
or graphic designers. Pick anchors that fit the post's tone. **Do not stack more than two.**

| Anchor | Best for |
|---|---|
| Annie Leibovitz | Portraits, environmental subjects with presence |
| Norman Rockwell's *editorial realism* | Grounded, warm human scenes (the realism quality, NOT cartooning) |
| Gregory Crewdson | Cinematic, staged, moody, quietly dramatic |
| Platon | Tight, high-contrast portraiture |
| Todd Hido | Quiet, atmospheric interiors and exteriors |
| Apple lifestyle photography | Clean, bright, aspirational, modern |
| National Geographic interior photography | Rich, authentic interior documentary |
| Documentary photojournalism | Candid, real, on-the-job authenticity |
| Bloomberg Businessweek / Inc. Magazine editorial | Professional, business-editorial polish |

## Matching anchors to tone

- Reassuring / trustworthy → Rockwell editorial realism, Apple lifestyle, Nat Geo interior
- Cautionary / serious → Crewdson, Todd Hido, documentary photojournalism
- Authoritative / professional → Platon, Bloomberg/Inc editorial
- Human / relationship-centered → Leibovitz, Rockwell editorial realism

Refinement: swap generic terms for concrete visual description. Favor literal, photographable
things over abstract concepts. Build in some contrast for visual interest. Don't overload the
scene with directions. Use exact color names and hex codes, not "warm tones."
