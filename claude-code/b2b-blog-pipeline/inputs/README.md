# inputs/

Drop your topic files here before running the pipeline.

Accepted formats:
- A filled-in `briefs/BLOG-BRIEF-TEMPLATE.md` (batch table or single-post form)
- A plain text or markdown file with topic ideas, one per line
- A research PDF or document to use as source material for Stage 0

Claude will detect the file type and enter the pipeline at the right stage.

Files in this folder are gitignored — nothing you drop here will be committed.
