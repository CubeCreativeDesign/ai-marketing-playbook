## What This Is

This is a collection of real-world AI workflows, Claude Project configurations, prompt templates, and full content pipelines that I use every day to run a digital marketing agency. No theory. No fluff. Just the stuff that actually works.

### Cowork or Claude Code?

Both pipelines follow the same stages and the same writing rules. The difference is how they run.

- **Cowork** reads plain instruction files. You point it at a topic and it works through the stages. Nothing to install.
- **Claude Code** runs a shell script that processes a whole batch of topics unattended, checks every draft with QC scripts, and builds cover images. It takes some setup (see its [tools guide](claude-code/b2b-blog-pipeline/docs/TOOLS.md)).

Start in Cowork. Move to Claude Code when you're running enough posts that the setup pays for itself.
