# Claude Project Templates

These are complete Claude Project configurations — including system instructions, recommended knowledge files, and usage examples. Each one is designed for a specific marketing workflow.

## How to Use These

1. **Create a new Project** in Claude (click "Projects" in the sidebar)
2. **Copy the system instructions** from the relevant template below into your project's custom instructions
3. **Upload the recommended knowledge files** (or your own versions)
4. **Start chatting** — Claude will follow the workflow automatically

## A Note on Customization

These templates are starting points. The best Claude Projects are the ones you've tweaked to match YOUR voice, YOUR clients, and YOUR processes. Don't just copy-paste — read through each one and ask yourself "what would make this work better for my specific situation?"
