# Getting Started with Claude for Marketing

New to Claude? Start here. This guide will get you from zero to productive without the tech jargon.

## The 30-Second Version

Claude isn't one thing — it's several tools under one roof:

- **Regular Chat** = Quick questions, brainstorming, one-off tasks
- **Projects** = Persistent workspaces with custom instructions and uploaded reference docs
- **Cowork** = Hands-off task automation (think: "do this to all 50 of these files")

Most of the workflows in this repo use **Projects** because that's where the magic happens for agency work. You set up the instructions once, and Claude knows your brand voice, your clients, your processes — every single time.
