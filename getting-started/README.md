# Getting Started with Claude for Marketing

New to Claude? Start here. This guide gets you from zero to productive without the tech jargon.

## The 30-Second Version

Claude isn't one thing. It's several tools under one roof:

- **Regular Chat** = Quick questions, brainstorming, one-off tasks
- **Projects** = Persistent workspaces with custom instructions and uploaded reference docs
- **Cowork** = Hands-off task automation in the desktop app (think: "work through all 14 of these blog topics")
- **Claude Code** = Claude in your terminal. It reads and writes files, runs scripts, and can process a whole batch while you do something else.

## Which One Should I Use?

| You want to... | Use | Try this template |
|---|---|---|
| Get a title package or check one post's links | **Projects** | [Projects](../projects/) |
| Write blog posts through a full research-to-publish process, no code | **Cowork** | [Private School Blog Pipeline](../cowork/private-schools/) |
| Run a batch of posts unattended, with automated QC | **Claude Code** | [B2B Blog Pipeline](../claude-code/b2b-blog-pipeline/) |

Most people should start with **Projects**. You set up the instructions once, and Claude knows your brand voice, your clients, and your processes every single time. When you catch yourself pasting the same five files into chat every week, that's your sign to try Cowork.

## Three Habits That Make Everything Work Better

1. **Give it a job, an audience, and a finish line.** "Write a blog post" gets you mush. "Write a 1,500-word post for private school admissions directors that ends with a CTA to book a call" gets you a draft.
2. **Make it show its sources.** Every statistic should come with a link you can click. The [Check Links](../projects/check-links.md) template exists because AI will happily invent a number.
3. **Check your prompts before you trust them.** The [Prompt Check](../projects/prompt-check.md) template grades a prompt and fixes the gaps. It takes two minutes and saves a lot of rework.
