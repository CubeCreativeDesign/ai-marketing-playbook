# Private School Reader Persona: [SCHOOL_TYPE / ROLE]

Use this template to define one reader persona. Create one persona per school type or decision-maker role you serve (for example, a college prep admissions director, a faith-based K-8 principal, or a virtual academy director). The goal is to make the writing feel like it was written for a specific person, not a segment.

This is the short, fill-in version. `reference/k-12-private-school-personas.md` has the long-form template and the category guide. Use whichever fits your team, then add each finished persona to `reference/k-12-private-school-personas.md` so Stage 1 and Stage 2 can find it. Base every persona on people you've actually talked to. Use fictional names, never a real client's.
