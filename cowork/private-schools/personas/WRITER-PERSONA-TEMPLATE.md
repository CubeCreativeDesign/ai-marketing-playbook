# Writer Personas: K-12 Private School

Use this template to define the writer voices for this vertical. Each persona should feel like a distinct, real person, not a tone descriptor. Add 2-3 sample voice sentences that could only come from that persona. If a writer has a quirk (analogies, sarcasm, questions), show it in the sample voice.

When you're done, copy your finished personas into `personas/writer-profiles.md`. That's the file Stage 2 and the batch table read. The three voices already in that file are examples you can keep, rename, or replace. If a voice is based on a real person on your team, get their OK before you publish under their name.
